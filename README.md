Personal Portfolio Website

A responsive personal portfolio website showcasing my **projects, technical skills, internships, certifications, achievements, and experience**.

 Features

* Responsive and mobile-friendly design
* About Me section
* Skills and technical expertise
* Internship and work experience
* Project showcase
* Certifications and achievements
* Contact section
* Modern and user-friendly UI

 Technologies Used

* HTML5
* CSS3
* JavaScript

 Project Structure

text
portfolio/
│
├── index.html
├── style.css
├── script.js
└── assets/
    └── images/


 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
